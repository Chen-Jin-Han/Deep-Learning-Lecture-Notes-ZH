## 项目简介

本仓库是一项持续维护的中文深度学习课程工程，目标是以结构化、可检索、可迭代的方式沉淀课程讲义及相关学术资料。内容从深度学习所需的数学基础出发，逐步扩展到经典模型、视觉模型、多模态预训练、大语言模型微调及推理强化学习。

本项目不是若干 PDF 的简单集合。仓库按照知识体系组织内容，并通过课程序号保留原始教学顺序。每个知识点均归入唯一的主要领域；存在跨领域联系时，通过课程索引建立关联，避免重复存储文件。

本项目将长期更新。现有内容可能根据理论发展、论文修订、教学反馈及内容审校持续调整。

3. 模型训练：第 1、5、15、18、19 课

## 版本管理原则

1. 修订讲义时优先保留稳定的课程序号及主题名称
2. 仅包含排版、标点或少量文字修订的更新，可直接替换正式版本并保留必要的旧版
3. 涉及章节重构、核心公式变更或结论修订时，应在提交记录中明确说明
4. 参考论文不使用课程序号作为唯一分类依据，而按照论文实际主题归档
5. 跨领域资料仅保留一份实体文件，通过 README 或相对链接建立索引
